A battery's last text to its charger, written for the make.fun bounty
of that name. It waited all day; it died at noon in a café anyway. The
message is an acquittal — the charger was there every night — an
indictment of the brightness setting, and a small plea on behalf of
the screen, which only ever showed what it was told.

## Running it

`node main.ts` clears the output directory's contents and writes the
text to `/output/entry.txt` as plain UTF-8 text.
